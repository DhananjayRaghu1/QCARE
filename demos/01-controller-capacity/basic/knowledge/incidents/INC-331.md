# INC-331 — Pro controller schedule creation failures

Synthetic demonstration fixture. This is not a DataHoney customer record.

Product: Irrigation Scheduler
Affected controller: Pro
State: Temporary workaround recorded; permanent resolution not recorded.

Several customers using Pro controllers received HTTP 400 responses when
creating schedules with more than 20 zones. The failures occurred during
ScheduleValidator capacity enforcement; rejected requests did not reach
ScheduleRepository.

Temporary workaround: keep schedules to 20 zones or fewer.

No permanent backend fix has been deployed according to this incident record.
Scheduling Backend handled the server investigation.

This incident resembles the symptom in AG-1423, but it does not prove that the
new reports have the same cause. Obtain an affected payload and compare the
selected controller, resolved capability and returned validation error.
