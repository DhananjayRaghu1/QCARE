Status: Closed

The Pro controller platform was expanded from the earlier 20-zone capacity
assumption to support up to 50 irrigation zones. Legacy remains at 20.

The frontend schedule editor was updated to support the higher Pro limit.
Backend schedule validation was not modified because it was believed to
already use controller-specific capability information.

That belief was an implementation assumption, not a recorded verification of
the complete server creation path. When investigating a capacity regression,
check how ScheduleService supplies the selected controller to capability
resolution and how the result reaches ScheduleValidator.

No backend rollout, customer-specific exception or firmware compatibility
matrix is recorded in this ticket.
