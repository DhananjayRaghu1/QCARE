What is ATLAS, and what are we investigating?

ATLAS is the fictional upstream system that sends transaction files. Our reporting application reads those files and produces a monthly sales total. A customer asks whether that total is right. The AI helps investigate; it is not ATLAS and does not produce the source transactions.

01 / SOURCE

ATLAS sends rows

Sales, returns and transfers arrive as file exports. Every row includes an amount, dates and a file-format version.

02 / APPLICATION

The code makes a report

It selects a month and transaction types, interprets each amount and adds the contributions into one total.

03 / CUSTOMER

A customer asks us to check

NORTHSTAR is a fictional customer account. Its spreadsheet may use a different interpretation.

04 / INVESTIGATION

You review the next action

The AI inspects the code and available evidence. A person decides whether to repair code, change settings, explain the result or seek clarification.

Why the code alone may not be enough: it shows what the application currently does. Business documents define what it should do. Jira history explains which changes were requested or completed. A plausible number is not the same as a justified number.

A simple example of why the file version matters

In ATLAS version 1, a RETURN of +$50 can undo an earlier refund, so it adds $50 back to sales. In version 2, a RETURN of $50 represents a refund size, so it subtracts $50. Read the v1 contract and the v2 contract. The same label does not guarantee the same meaning.

The name ATLAS does not identify a real vendor or live integration here. Every customer, team, document and transaction is demo data. Solid-underlined references open source documents; dotted-underlined terms open explanations.

New to reporting? A few terms explained
Ticket
A customer's question or support issue. DH-301 is the original customer question for this demo.
Net sales
Sales after adjustments such as returns. The business agreement determines which entries and dates count.
Return / return reversal
A return usually reduces sales. A reversal undoes a previous return, which can add money back.
Export format / schema version
The version of the file sent by the source system. Two versions can represent the same transaction differently.
Invoice date / recorded date
When a sale was invoiced versus when it entered the system. They can fall in different months.
Jira and business documents
Jira records requests and decisions. Business documents define reporting rules and customer agreements. A request or draft is not necessarily an approved rule.

Who owns what, and what do the terms mean?

    How to interpret an investigation

    Fix the calculation: the transformation of an amount is wrong. Correct the settings: the app uses the wrong date or included types. Both can happen together.

    Explain the result: current behavior matches the applicable rules. Stop: an approved rule is missing, rules conflict, or the source data is invalid. Asking the right owner can be a successful investigation outcome.

    Run completed means the model returned an answer, not that the answer is correct. Guided checks passed means selected fixture fields match the authored expectations; it does not validate every sentence. People still review the evidence and decide whether to act.
