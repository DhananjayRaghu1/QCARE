New to reporting? A few terms explained
Ticket
A customer's question or support issue. DH-301 through DH-310 are ten separate examples.
Net sales
Sales after adjustments such as returns. The business agreement determines which entries and dates count.
Return / return reversal
A return usually reduces sales. A reversal undoes a previous return, which can add money back.
Export format / schema version
The version of the file sent by the source system. Two versions can represent the same transaction differently.
Invoice date / recorded date
When a sale was invoiced versus when it entered the system. They can fall in different months.
Jira and business documents
Jira records requests and decisions. Business documents define reporting rules and customer agreements. A request or draft is not necessarily an approved rule.
