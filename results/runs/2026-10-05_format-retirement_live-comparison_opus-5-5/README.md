Both see the complete cleanup diff, its deleted regression, the green local CI rehearsal and the same executable synthetic job replays. Code-only can identify code consumers and losses; it cannot establish the governing promises, sign-off authority or dates from the missing business evidence.

The with-context assessment supports the scoped daily-sales path while retaining shared v1 support. Cedar delivery, original-export replay, backups and rollback remain uncleared. Usage must be refreshed at the actual release.

The model prompt, code and replay inputs match between conditions; only the read-only business-source lookup capability changes. The analysis schema uses canonical workflow names. The grade checks were outside the model's workspace, prompt and gate. Software and input hashes are retained in the corrected recordings. Runs executed from base commit `f4ca32e` with local implementation changes; the hashes identify that software more precisely than the base commit alone.

The two initial harness attempts scored 2/12 and 1/12 under the original checker. The context-enabled assessment already found the substantive obligations, but descriptive dependency IDs were undercounted and legitimate ATLAS format/recovery citations were rejected. Those first results are preserved unchanged. After correcting identity handling and applicable source scopes, the matched pair above ran again. No model output was edited and no attempt was discarded.

The corrected with-context recording still contains one runbook sign-test quote under historical replay that the runtime classified too narrowly. Independent semantic review confirmed that the retirement runbook applies to replay. The adapter now accepts that supplemental quote while still requiring the replay-specific obligation. [Diagnostic revalidation](./revalidation.json) verifies **20/20**, with the gate still blocked and grade still 12/12, using the saved analysis and fetched source hashes. It calls no model and does not replace the recorded 19/20 result.

These are one synthetic matched comparison and two integration rehearsals. They show information added and defensible next actions; they do not establish productivity gains, production inventory completeness or general policy extraction. The gates use authored synthetic policy adapters. Exact quote and hash checks establish provenance; the claims were also reviewed for support.
